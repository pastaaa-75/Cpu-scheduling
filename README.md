# Dispatch — เครื่องมือจำลองและวัดผลการจัดตารางเวลาของ CPU (CPU Scheduling Bench)

**Dispatch** เป็นเครื่องมือจำลองการทำงานของการจัดตารางเวลา CPU (CPU Scheduling Simulator) แบบโต้ตอบ ทำงานบนเว็บเบราว์เซอร์ พัฒนาขึ้นเพื่อช่วยให้เห็นภาพและประเมินประสิทธิภาพของอัลกอริทึมการจัดตารางเวลา CPU ยอดนิยม คุณสามารถป้อนข้อมูลภาระงาน (Workload) ของโปรเซสด้วยตัวเอง หรือเลือกจากชุดข้อมูลตัวอย่างคลาสสิก เพื่อวิเคราะห์แผนภูมิ Gantt Chart, เล่นภาพการทำงานทีละขั้นตอน (Playback), ตรวจสอบค่าเมตริกของแต่ละโปรเซส และเปรียบเทียบประสิทธิภาพระหว่างอัลกอริทึมต่างๆ ได้แบบเรียลไทม์

## 🌟 คุณสมบัติเด่น (Key Features)

* **รองรับ 6 นโยบายการจัดตารางเวลา (Scheduling Policies):**
  * **FCFS** (First-Come, First-Served) — มาก่อน ได้รับบริการก่อน
  * **SJF** (Shortest Job First — Non-preemptive) — งานสั้นที่สุดได้ทำก่อน (ห้ามแทรกกลางคัน)
  * **SRTF** (Shortest Remaining Time First — Preemptive SJF) — งานที่เหลือเวลาน้อยที่สุดได้ทำก่อน (แทรกกลางคันได้)
  * **Priority (Non-preemptive)** — จัดลำดับตามความสำคัญ (ห้ามแทรกกลางคัน)
  * **Priority (Preemptive)** — จัดลำดับตามความสำคัญ (แทรกกลางคันได้)
  * **Round Robin** — ผลัดกันทำงานตามช่วงเวลาที่กำหนด (Time Quantum)

* **ฟังก์ชันการจำลองระดับสูง:**
  * กำหนดเวลาสูญเสียจากการสลับบริบทการทำงาน (**Context Switch**) ได้
  * แผนภูมิ **Gantt Chart** แบบโต้ตอบ พร้อม Tooltip แสดงรายละเอียด และปุ่มควบคุมการเล่นจำลองเวลา (Play / Step)
  * คำนวณค่าเมตริกละเอียดแยกตามโปรเซส: เวลาเสร็จสิ้น (**Completion Time**), เวลาวนรอบ (**Turnaround Time**), เวลาการรอ (**Waiting Time**), และเวลาตอบสนอง (**Response Time**)
  * ตารางเปรียบเทียบ 6 อัลกอริทึมแบบเรียลไทม์สำหรับภาระงานเดียวกัน

* **ไม่ต้องมี Dependencies เพิ่มเติม:** เขียนด้วย HTML5, CSS3 และ JavaScript (ES6+) แท้ๆ ทำงานบน Web Browser ทั้งหมดโดยไม่ต้องพึ่งพาเซิร์ฟเวอร์
* **รองรับการทำงานบน Node.js:** ตัวประมวลผลอัลกอริทึม (`engine.js`) ถูกออกแบบให้แยกออกจากส่วนแสดงผล (DOM) จึงสามารถนำไปรันหรือเขียน Unit Test บน Node.jsได้ทันที

| ชื่อไฟล์ | ประเภท | หน้าที่การทำงาน |
| ----- | ----- | ----- |
| `index.html` | โครงสร้างหน้าเว็บ (UI Template) | กำหนดโครงสร้าง HTML ของแผงควบคุม, ตารางป้อนข้อมูล, พื้นที่แสดงผล Gantt Chart และปุ่มปฏิสัมพันธ์ต่างๆ |
| `styles.css` | สไตล์ชีท (Stylesheet) | ตกแต่งหน้าตา จัดการเลย์เอาต์ responsive, กำหนดชุดสีของแต่ละโปรเซส และรองรับระบบ Light/Dark Mode |
| `engine.js` | ประมวลผลหลัก (Core Logic) | เป็น Pure JavaScript Library คำนวณลำดับเวลาการทำงานของแต่ละอัลกอริทึม ประมวลผล Gantt Chart และค่า статистиกต่าง ๆ |

## 📐 สูตรคำนวณค่าเมตริก (Mathematical Formulas)

กำหนดให้:
* $AT$ คือ เวลาที่มาถึง (Arrival Time)
* $BT$ คือ เวลาที่ใช้ประมวลผล (Burst Time)
* $CT$ คือ เวลาที่ทำงานเสร็จสิ้น (Completion Time)
* $ST$ คือ เวลาที่เริ่มทำงานครั้งแรก (Start Time)

สูตรคำนวณพื้นฐานมีดังนี้:

* **Turnaround Time ($TAT$):** 
  $$TAT = CT - AT$$

* **Waiting Time ($WT$):** 
  $$WT = TAT - BT$$

* **Response Time ($RT$):** 
  $$RT = ST - AT$$

* **CPU Utilization ($U$):** 
  $$U = \frac{\sum BT}{\text{Total Time}}$$

## 🚀 วิธีการใช้งาน (Quick Start)

### รันผ่าน Web Browser
1. ดาวน์โหลดหรือ Clone โปรเจกต์นี้
2. เปิดไฟล์ `index.html` บน Web Browser (เช่น Chrome, Firefox, Edge, Safari) ได้ทันที

### รันการทดสอบผ่าน Node.js
หากต้องการทดสอบความถูกต้องของ Logic ใน `engine.js` สามารถเปิด Terminal ในโฟลเดอร์โปรเจกต์แล้วรันคำสั่ง:

```bash
node test.js
```

หากการทำงานถูกต้องทั้งหมด ระบบจะแสดงข้อความ `all engine tests passed`
